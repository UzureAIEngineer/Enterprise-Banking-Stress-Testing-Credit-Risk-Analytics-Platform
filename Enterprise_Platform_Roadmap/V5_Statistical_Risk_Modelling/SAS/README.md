# SAS Implementation

## Framework Overview

This SAS implementation is part of the Enterprise Banking Stress Testing & Credit Risk Analytics Platform.

The framework supports regulatory risk analytics and reporting across a 200,000-account banking portfolio and includes:

- Enterprise Portfolio Generation
- Risk Feature Engineering
- Risk Segmentation
- Probability of Default (PD) Analytics
- Loss Given Default (LGD) Analytics
- Exposure at Default (EAD) Analytics
- Expected Credit Loss (ECL) Calculation
- Stress Testing & Scenario Analysis
- Executive Risk Dashboard
- SAS vs Python Benchmarking
