PURPOSE
-------

The Risk Feature Engineering module enriches the enterprise portfolio
generated in Module 01 by deriving analytics-ready risk features.

These engineered variables are used to support:

- Segmentation Analysis
- PD Analytics
- LGD Analytics
- EAD Analytics
- ECL Calculation
- Stress Testing

==============================================================================

BUSINESS OBJECTIVE
------------------

Raw portfolio data often lacks analytical variables required for
credit risk assessment.

This module creates business-relevant risk indicators which improve
portfolio analysis and support regulatory reporting requirements.

==============================================================================
